## 背景

- 183cm / 130kg，伴郎日 2026-10-25（还有 175 天）
- 贪吃、意志力薄弱、身体素质差、总是放弃
- 正在做的运动：爬楼梯（有氧）、死虫式、深蹲、靠墙静蹲（无氧）
- 未来希望在克服身材焦虑后去游泳（6-9月）

## 放弃模式诊断

**触发机制：** 破堤效应（abstinence violation effect）。一次违规不是被当作一次违规，而是被当作"全盘失败"的信号。

具体表现：
1. 晚上饿得受不了点外卖 → 觉得"今天破了戒，算了"→ 崩盘
2. 工作忙缺勤锻炼 → 连锁崩塌
3. 数字焦虑、终点模糊、过程枯燥、没有里程碑 → "一眼望不到头"

## 心理货币

**最强的正反馈来源：** 回看一张布满标记的地图——"天哪我已经去过 17 个城市了"。

类比：旅游不需要意志力，因为新鲜感 + 可见位移进度 + 具体期待 + 每次都是一个有头有尾的故事。

**情绪高峰排序：** 回看积累 > 途中进度 > 抵达瞬间 > 行前期待

## 核心设计决策

### 产品形态
- Python CLI 工具（非手机 APP），参考 hermes-agent 技术栈
- 终端里跑，纯个人使用
- 每天上班时打开看今日任务

### 核心体验
- 像素风迷雾航海地图，每天完成任务揭示一格
- LLM 生成航海日志（叙事 + 随机事件 + 教练对话）
- 主题可切换（先做航海主题，后续可扩展修仙等）

### 破戒处理
- **驿站系统**：破戒不出现空白或惩罚，地图上出现"驿站"图标
- **休整令牌**：每连击 7 天自动产一枚，用于吸收例外日，不用不累积
- 叙事重构：不是"我失败了"，而是"航程中必要的休整"

### 每日必定任务
- 方案 C（极低必定 + 超额加分）
- 每日打开看到最低门槛任务，完成即推进
- 超额完成可加更多（最多 3 格/天）
- AI 健身大师可对话调整任务（方案 B：可选对话）

### 航线设计
175 天分 6 阶段 + 随机航点（3-7 天）+ 真实日历节日锚点：

| 阶段 | 天数 | 主题 |
|------|------|------|
| 启航 | 1-14 | 建立习惯 |
| 迷雾之海 | 15-45 | 接受波动 |
| 季风带 | 46-90 | 习惯成自然 |
| 群岛航道 | 91-130 | 游泳期，黄金减重 |
| 远望线 | 131-165 | 身材明显变化 |
| 陆地！ | 166-175 | 伴郎前准备周 |

### 终点画面
> "婚礼上能和老朋友自如地聊天，不会因为身材自卑而躲在角落。另外全场目光在新郎新娘身上，但如果我因为身材被注意到，会倍感压力和焦虑。"

### 技术栈
- Python 3.12 + `rich`（终端 UI）+ SQLite WAL
- OpenAI 兼容 LLM API
- `uv` 管理依赖
- 数据目录：`~/.bestman/`

### 10/25 之后
新航线模式——完成一条航线后可以开启新的（换主题、新目标），永续引擎。
