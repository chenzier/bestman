# 饮食技术路线

> 优先级：远期  
> 定位：非审判式记录，可选模块

## 新定位

饮食不是当前主线。只有当宠物船打卡体验稳定后，才考虑加入。

如果加入，原则是：

- 不追踪复杂卡路里。
- 不审判。
- 不把饮食变成新的压力源。
- 只做温和记录和反馈。

## 可能命令

```bash
bestman eat "午餐：鸡胸肉沙拉 + 糙米饭"
bestman eat --type breakfast "燕麦粥 + 鸡蛋"
bestman eat --week
```

## 数据模型

仍使用事件源：

```text
MealRecorded
```

projection 可维护：

- 当天饮食记录
- 本周记录数
- 最近几条饮食文本

## LLM 边界

LLM 可以：

- 给 1-2 句温和反馈。
- 根据最近几条记录做轻量总结。
- 用宠物船/厨子语气表达鼓励。

LLM 不应：

- 生成羞辱性评价。
- 做医学营养诊断。
- 给极端节食建议。

## 暂缓

- 厨子船员绑定。
- 食谱系统。
- 营养素计算。
- 饮食连续任务。
