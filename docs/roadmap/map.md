## v3.0 — 动态地图

| 元素 | 说明 |
|------|------|
| 天气系统 | 每天根据日期种子随机天气，影响掷骰权重和画面效果 |
| 昼夜交替 | 根据系统时间切换色调（暖/冷/暗） |
| 海生物 | 随机刷新位置，每次 render 不同（🐋🐬🐟） |
| 移动动画 | done 后船逐格动画移动，而非瞬移 |

### 天气类型

| 天气 | 视觉 | 掷骰影响 |
|------|------|----------|
| 晴朗 ☀️ | 明亮色调、平静水面 | 正常 |
| 多云 ☁️ | 灰白水面、低光照 | 正常 |
| 大风 🌬️ | 波浪纹理、飘动效果 | 掷骰 +1（顺风） |
| 暴雨 ⛈️ | 深色天空、雨丝效果 | 掷骰下限 1（逆风风险） |
| 迷雾 🌫️ | 降低迷雾透明度、视野缩小 | 正常 |

### 昼夜

- 根据当前系统时间，渲染时套一层半透明 color overlay
- 白天：正常色板
- 黄昏：暖橙 overlay 30%
- 夜晚：深蓝 overlay 50%

## v3.1 — 创意工坊

- `MapEngine.from_file()` 已是预留接口
- 用户自定义地图（YAML 格式）
- 社区地图分享、安装/导出

### 自定义地图格式

```yaml
name: "海盗航线"
width: 50
height: 14
stages:
  - name: "风暴角"
    days: [1, 30]
    terrain: "storm"
    texture: "choppy"
  - name: "暗礁区"
    days: [31, 60]
    terrain: "reef"
    texture: "ripple"
milestones:
  25: "穿越风暴角"
  50: "驶出暗礁区"
```
