# 地图/航线技术路线

> 优先级：中低  
> 定位：长期进度背景，不是主玩法

## 新定位

地图不再承担“航海游戏主舞台”。它只回答一个问题：

```text
我已经坚持了多远？
```

宠物船负责每日情绪和互动；地图负责长期进度和里程碑。

## 当前 Rust 状态

- `Route::generate(total_days)` 生成 50×14 航线。
- TUI 中地图已降级为 compact route/progress。
- dashboard PNG 仍有完整路线图。
- 当前 marker 只是进度表达，不等同于宠物船本体。

## v1 目标

- TUI 中只展示轻量航线进度，不抢宠物船注意力。
- dashboard PNG 可保留完整路线图，用于分享/回顾。
- 里程碑可以由路线进度触发，但表现应回到宠物船和日志。

## v2 可做

- 里程碑节点命名。
- 航线阶段色彩。
- 打卡后短暂 route progress 动画。
- PNG 分享图更精致。

## 暂缓

以下旧路线暂缓：

- 天气影响掷骰。
- 昼夜/动态海生物。
- 创意工坊地图。
- 社区地图市场。

原因：这些会把注意力拉回“地图游戏”，和当前宠物船-first 方向冲突。
