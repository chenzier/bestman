# 健身/体重技术路线

> 优先级：v2/v3  
> 定位：健康记录与反馈，不制造焦虑

## 当前 Rust 状态

Rust 版当前只实现了每日打卡级别：

- light
- normal
- full
- skip/rest

还没有体重记录、伤病咨询、动作指导。

## v1 目标

先把打卡闭环做扎实：

- 今日任务可见。
- 完成级别清楚。
- 打卡反馈温柔，不羞辱用户。
- 休息是正当状态，不是失败。

## v2 体重记录

可加入轻量命令：

```bash
bestman weigh 72.5
bestman progress
```

数据仍走事件源：

```text
WeightRecorded
```

SQLite projection 可维护：

- 最新体重
- 最近 N 次体重
- 趋势摘要

## v3 健康建议

LLM 可以用于：

- 体重趋势的温和总结。
- 训练动作替代建议。
- 疲劳时降低强度的文案。

边界：

- 不做诊断。
- 不给高风险医疗建议。
- 明确建议严重疼痛时寻求专业帮助。

## 暂缓

- 体态照片。
- 自动伤病识别。
- 队医角色深度对话。
- 高精度热量/营养追踪。
