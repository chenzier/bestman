# bestman

航向新大陆 — 175 天的航海健身之旅。

一个 Claude Code skill，把减肥变成一场像素风航海冒险。每天完成最小门槛任务 → 在多雾地图上前进一格 → AI 导航员撰写航海日志。

**目标：** 2026 年 10 月 25 日抵达新大陆，作为伴郎自信地站在婚礼上。

## 如何使用

在 Claude Code 中输入：
```
/bestman
```

你将看到：
- 一张像素风航海地图（迷雾逐渐揭开）
- 今天的必定任务（极低门槛）
- 连击天数、休整令牌、阶段名

## 命令

| 输入 | 作用 |
|------|------|
| `/bestman` | 查看仪表盘和今日任务 |
| `done` | 完成今日任务，推进地图 |
| `done +2` | 超额完成，额外推进 |
| `skip` | 使用休整令牌，保留连击 |
| 自由对话 | 和 AI 导航员聊天（调整任务、咨询、打气） |
| `log` | 查看最近航海日志 |

## 设计哲学

- **完成比完美重要**：每天的最低门槛低到没有借口不做
- **一次破戒≠全盘失败**：驿站是航海的一部分，不断连击
- **回看积累是最强的心理货币**：地图标记只增不减
- **AI 不是教官，是老练的导航员**：建议而不施压
